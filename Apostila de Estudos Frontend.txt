🌐 Aula 1 — O que é HTML?
1️⃣ Conceito ELI5 (explicação de criança)

Imagine que você vai construir uma casa.

Antes de pintar, decorar ou colocar móveis, você precisa do esqueleto da casa:

onde fica a porta

onde ficam os quartos

onde fica a cozinha

Esse esqueleto da casa é o HTML.

Ele organiza as coisas, mas não deixa bonito.

Na internet funciona assim:

Tecnologia	Função
HTML	Estrutura
CSS	Aparência
JavaScript	Comportamento

Uma analogia divertida:

HTML é o corpo
CSS é a roupa
JavaScript é o cérebro

Sem HTML… nada existe na página.

🧠 Por que isso importa (Big Tech)

Empresas gigantes como:

Meta

Google

Netflix

têm milhões de páginas rodando.

Se o HTML for mal feito:

leitores de tela não funcionam

SEO quebra

performance piora

manutenção vira um inferno

Engenheiros frontend seniores são obcecados por HTML semântico.

🧩 Seu primeiro código HTML

Crie um arquivo chamado:

index.html

Agora coloque isto dentro:

<!DOCTYPE html>
<html>
<head>
  <title>Meu Primeiro Site</title>
</head>

<body>

  <h1>Olá mundo!</h1>

  <p>Este é meu primeiro site.</p>

  <button>Clique em mim</button>

</body>
</html>

Agora vamos desmontar isso linha por linha.

🧠 Explicação linha por linha
<!DOCTYPE html>

Isso diz ao navegador:

"Ei navegador, este arquivo usa HTML moderno."

<html>

Aqui começa todo o site.

Tudo que aparece na página precisa estar dentro dessa tag.

<head>

Essa parte guarda informações do site, não o que aparece na tela.

<title>Meu Primeiro Site</title>

Isso define o nome que aparece na aba do navegador.

<body>

Agora começa o conteúdo visível da página.

<h1>Olá mundo!</h1>

h1 significa Heading 1.

É o título principal da página.

<p>Este é meu primeiro site.</p>

p significa parágrafo.

Texto normal.

<button>Clique em mim</button>

Um botão clicável.

Depois vamos ensinar o JavaScript a reagir ao clique.

1️⃣ FUNDAMENTOS DA WEB

As fundações do prédio.

Sem isso o prédio cai.

Tecnologias:

HTML

CSS

JavaScript básico

Analogia simples:

HTML = estrutura da casa
CSS = decoração da casa
JS = eletricidade da casa

Todo site do mundo usa isso.

Inclusive o interface do ChatGPT feito pela OpenAI começa aqui.

2️⃣ LINGUAGEM DE PROGRAMAÇÃO

Aqui mora o cérebro.

Tecnologia principal:

JavaScript

E sua versão moderna:

TypeScript

Analogia divertida:

JavaScript é como falar português.

TypeScript é português com regras gramaticais obrigatórias.

Resultado:

menos bugs
menos caos
mais previsibilidade

Por isso praticamente todas as Big Techs migraram para TypeScript.

3️⃣ FRAMEWORK DE INTERFACE

Agora entra a fábrica de interfaces.

Tecnologia dominante:

React

Criado por:

Meta

Analogia LEGO:

Você cria peças pequenas:

Botão
Card
Navbar
Perfil

Depois monta sistemas gigantes:

Instagram
Netflix
Airbnb
4️⃣ META FRAMEWORK

React sozinho é só um motor.

Você ainda precisa montar:

rotas

SEO

servidor

otimizações

Aí entra o Next.js.

Ele é tipo React com superpoderes.

Criado pela empresa:

Vercel

Ele adiciona:

roteamento automático

renderização no servidor

performance absurda

SEO

Hoje a maioria das startups começa com Next.js direto.

5️⃣ GERENCIAMENTO DE ESTADO

Agora entra um problema clássico.

Imagine um app grande.

Muitos componentes precisam acessar dados:

usuário logado

carrinho

tema

notificações

Guardar isso em cada componente vira caos.

Então criamos estado global.

Ferramentas modernas:

Zustand

Redux (clássico)

Context API

Analogia:

Estado local = bolso da calça
Estado global = geladeira da casa

6️⃣ COMUNICAÇÃO COM BACKEND

Frontend não vive sozinho.

Ele conversa com servidores.

Tipos de comunicação:

REST API
GraphQL
Server Actions (Next.js moderno)

Biblioteca dominante:

TanStack Query

Ela faz:

cache

sincronização

refetch automático

controle de loading

Isso é engenharia de dados frontend.

7️⃣ PERFORMANCE

Empresas como Google descobriram algo curioso:

100ms de atraso reduz conversão.

Então frontend precisa otimizar:

code splitting

lazy loading

memoização

streaming

Frontend moderno é quase engenharia de performance.

8️⃣ TESTES

Código sem teste é uma bomba-relógio.

Ferramentas comuns:

Jest
Testing Library
Playwright
Cypress

Testes garantem que mudanças não quebrem o sistema.

🏗️ 1 — TAGS DE ESTRUTURA (o esqueleto da página)

Essas organizam o layout da página.

<html>

É o container do site inteiro.

<html>
  <!-- todo o site vive aqui -->
</html>
<head>

Informações para o navegador.

<head>
  <title>Meu Site</title>
</head>

Nada daqui aparece visualmente.

<body>

Aqui vive tudo que aparece na tela.

<body>
  <h1>Olá mundo</h1>
</body>
<header>

Topo do site.

<header>
  <h1>Meu Blog</h1>
</header>

Normalmente contém:

logo

menu

título

<main>

Conteúdo principal da página.

<main>
  <p>Conteúdo principal</p>
</main>

Motores de busca gostam muito dessa tag.

<footer>

Rodapé.

<footer>
  <p>Copyright 2026</p>
</footer>
📝 2 — TAGS DE TEXTO

Essas exibem conteúdo textual.

<h1> até <h6>

Títulos.

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Seção</h3>

Regra de ouro:

h1 = título da página
h2 = seções
h3 = subseções
<p>

Parágrafo.

<p>Este é um texto.</p>
<span>

Pequeno pedaço de texto.

Muito usado para estilizar algo específico.

<p>Meu nome é <span>Richard</span></p>
<strong>

Texto importante.

<strong>Atenção!</strong>

Navegadores geralmente deixam negrito.

🧭 3 — TAGS DE NAVEGAÇÃO

Permitem navegar pelo site.

<a> (link)

Uma das tags mais importantes da web.

<a href="https://google.com">
  Ir para o Google
</a>

A web inteira funciona baseada nisso.

Foi literalmente a invenção revolucionária de
Tim Berners-Lee.

<nav>

Container de navegação.

<nav>
  <a href="/">Home</a>
  <a href="/sobre">Sobre</a>
</nav>

Menus quase sempre usam isso.

<ul> lista

Lista não ordenada.

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
<li> item da lista
<li>Produto</li>

FASE CSS — Transformando seu site em algo profissional
1️⃣ Conceito ELI5

Se o HTML é a casa…

O CSS é:

pintura 🎨

Com CSS… ele começa a parecer um produto real.

🧠 Por que isso importa (nível Big Tech)

Empresas como Netflix e Airbnb investem MUITO em:

experiência visual
consistência

Um frontend bonito não é luxo. É conversão.

Um layout ruim = usuário sai em segundos.

🧱 PASSO 1 — Conectar o CSS ao HTML

Crie um arquivo:

style.css

Agora, dentro do seu HTML (perfil.html), adicione no <head>:

<link rel="stylesheet" href="style.css">

👉 Isso conecta o CSS ao seu site.

🎨 PASSO 2 — Primeiro CSS da sua vida (comentado)

Agora no style.css:

/* Remove espaçamentos padrão do navegador */
body {
  margin: 0;
  font-family: Arial, sans-serif;
  background-color: #f4f4f4;
}

/* Cabeçalho */
header {
  background-color: #111;
  color: white;
  padding: 20px;
  text-align: center;
}

/* Menu */
nav {
  background-color: #333;
  padding: 10px;
  text-align: center;
}

/* Links do menu */
nav a {
  color: white;
  margin: 0 10px;
  text-decoration: none;
}

/* Efeito ao passar o mouse */
nav a:hover {
  text-decoration: underline;
}

/* Conteúdo principal */
main {
  padding: 20px;
}

/* Seções */
section {
  margin-bottom: 30px;
}

/* Rodapé */
footer {
  background-color: #111;
  color: white;
  text-align: center;
  padding: 10px;
}
🔍 Explicação simples (sem complicar)
body { ... }

👉 Aplica estilo no corpo inteiro do site

header { ... }

👉 Estiliza o topo

nav a { ... }

👉 Estiliza TODOS os links dentro do menu

nav a:hover { ... }

👉 Quando passa o mouse 👀

🧠 Agora entra coisa de engenheiro (Flexbox)

Vamos dar um upgrade nível real de mercado.

🔥 PASSO 3 — Layout moderno com FLEXBOX

Adicione no seu CSS:

/* Centralizar conteúdo e limitar largura */
main {
  max-width: 800px;
  margin: auto;
}

👉 Isso deixa o site com cara de produto real.

Agora vamos melhorar o menu:

nav {
  display: flex;
  justify-content: center;
  gap: 20px;
}
🧠 ELI5 do Flexbox

Flexbox é tipo organizar coisas na mesa:

display: flex → ativa o modo organização
justify-content → organiza horizontal
gap → espaço entre itens
🎯 Desafio prático (nível upgrade)

Agora você vai brincar um pouco:

1️⃣ Troque cores (use cores mais modernas tipo: #0f172a, #1e293b)
2️⃣ Aumente o tamanho do título (font-size)
3️⃣ Centralize tudo bonitinho
4️⃣ Coloque uma borda nas seções:

section {
  border: 1px solid #ccc;
  padding: 15px;
  border-radius: 8px;
}
